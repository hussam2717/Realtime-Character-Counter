# Realtime-Character-Counter
 A clean and responsive Character Counter web app built using HTML, CSS, and JavaScript.   It tracks the number of characters typed in real-time and displays the remaining character limit dynamically.

## Live Demo -

## 🚀 Features
- Real-time character counting
- Maximum character limit tracker
- Responsive modern UI
- Smooth and minimal design
- Live typing feedback
- Beginner-friendly project

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript

## 📂 Project Structure
├── index.html
├── style.css
└── script.js

## ⚡ How It Works
User types inside the textarea
JavaScript detects input events
Character count updates instantly
Remaining limit decreases dynamically
